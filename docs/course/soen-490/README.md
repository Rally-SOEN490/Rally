## Passing and individual obligations

- Every student must demonstrate substantial engineering design and implementation on complex, open-ended problems in each iteration, with regular work throughout both terms. A student can fail even when the team passes. Document unsuccessful experiments with code and reasons; a well-evidenced failed attempt can still earn credit.
- Pass the final release and presentation to pass the course. Record individual work as required in [release notes](RELEASES.md#iteration-and-release-notes); missing contributions or evidence can earn zero.
- Complete [OHS](https://moodle.concordia.ca/moodle/mod/forum/discuss.php?d=1288300) by **November 2, 2026, 11:59 PM**: 75% to pass, unlimited attempts, highest score retained. It does not affect the SOEN 490 grade; incompletion blocks main-course grade release.
- Attend at least two [law lectures](https://moodle.concordia.ca/moodle/mod/forum/discuss.php?d=1291371). Join the [Jurist-in-Residence mailing list](https://lists.concordia.ca/cgi-bin/wa?SUBED1=JURIST-IN-RESIDENCE-INVITATION&A=1) and register for Concordia slots.
