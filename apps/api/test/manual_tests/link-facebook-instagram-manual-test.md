- **Link Instagram and Facebook and open the associated apps** — **Manual**

  **Prerequisites:** Use a test Rally account, a test Instagram account, and a
  test Facebook account on a device with the Instagram and Facebook apps
  installed and signed in. Use the profile URLs for those test accounts.

  1. Sign in to Rally and open **Profile**.
  2. Open **Settings**, enter the test Instagram profile URL in **Instagram
     link**, and select **Save link**.
  3. Enter the test Facebook profile URL in **Facebook link** and select **Save
     link**.
  4. Return to **Profile** and confirm both Instagram and Facebook show
     **Connected**.
  5. Tap the Instagram icon. Confirm the Instagram app opens to the linked
     test profile.
  6. Return to Rally, tap the Facebook icon, and confirm the Facebook app opens
     to the linked test profile.
  7. Return to Rally, reopen **Settings**, and confirm both saved URLs are still
     present.

  **Expected result:** Valid Instagram and Facebook links can be saved to the
  profile, remain persisted, and tapping each connected icon opens its
  associated app at the linked profile. If an app is unavailable on the device,
  the platform may open the URL in a browser instead.
