# Player-card artwork

Read-only exports from Rally's [Search Page - Players reference](https://www.figma.com/design/oHEZGk9It7Kou7bcVeJX9M/?node-id=2038-1233).

- `match.svg`: volleyball match metric.
- `wins.svg`: crown metric, node `2038:1469`, exported with text outlined.
- `events.svg`: calendar metric, node `2038:1475`, exported with text outlined.
- `invite.svg`: invitation icon.
- `profile-button.svg` and `invite-button.svg`: action backgrounds.

The SVG geometry is preserved from the design. Assets are bundled locally; the
application does not load temporary Figma URLs. Inter font files and their OFL
license are in `../../fonts/inter/`.
