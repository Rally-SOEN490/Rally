# Player-card artwork

Read-only exports from Rally's [Search Page – Players reference](https://www.figma.com/design/oHEZGk9It7Kou7bcVeJX9M/?node-id=2038-1233), card `2038:1246`, inspected November 2, 2026.

- `match.svg`, `wins.svg`, `top-four.svg`, `events.svg`: exact outlined metric glyphs from nodes `2038:1462`, `2038:1469`, `2408:310`, `2038:1475`.
- `format-dot.svg`, `position-dot.svg`, `level-dot.svg`, `gender-dot.svg`: interest markers from `2038:1265`, `2371:230`, `2038:1289`, `2038:1340`.
- `selected-interest.svg`, `check.svg`, `dropdown.svg`: selected format background, check, and overflow caret from `2038:1263`, `2038:1430`, `2415:324`.
- `profile-button.png`, `message-button.png`: exact 3x artwork exports from `2038:1313` and `2038:1267`. PNGs avoid the edge artifacts seen with the SVG backgrounds in the Android image renderer.

Assets are bundled locally; no temporary Figma URL is used at runtime. Inter font files and their OFL license remain in `../../fonts/inter/`. Figma's sample statistics and interests are not application defaults. The selected-format appearance requires a supplied active preference; the current directory has no active filters.
